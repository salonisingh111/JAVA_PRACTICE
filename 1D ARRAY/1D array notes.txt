JAVA 1D ARRAY – IMPORTANT NOTES

1. Declaration
int[] arr;
int arr[];

2. Initialization
int[] arr = new int[5];

3. Direct Values
int[] arr = {10, 20, 30};

4. Access Elements
System.out.println(arr[0]);

5. Update Elements
arr[1] = 50;

6. Length
arr.length

7. Loop Through Array
for(int i = 0; i < arr.length; i++){
    System.out.println(arr[i]);
}

8. Enhanced For Loop
for(int num : arr){
    System.out.println(num);
}

9. Default Values
int -> 0
double -> 0.0
boolean -> false
String -> null

10. Common Operations
- Sum of elements
- Maximum element
- Minimum element
- Reverse array
- Search element
- Sort array

11. Important Methods
Arrays.sort(arr);
Arrays.toString(arr);

Import:
import java.util.Arrays;

12. Common Errors
- ArrayIndexOutOfBoundsException
- NullPointerException

13. Time Complexity
Access -> O(1)
Search -> O(n)

14. Interview Points
- Array size is fixed
- Stores same datatype
- Continuous memory allocation

15. Most Asked Logic
- Second largest element
- Duplicate detection
- Frequency count
- Rotate array
- Palindrome array

16. Best Practice
Always use:
for(int i = 0; i < arr.length; i++)

instead of hardcoded size.
